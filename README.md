# JobSeek

A professional global job-discovery and application-preparation platform.

## Current features
- Responsive recruitment website
- Job search and country filtering
- Visa-sponsorship information area
- Application Assistant
- Job-description keyword extraction
- ATS-readiness guidance
- Missing-keyword detection
- Tailored CV and cover-letter drafts based only on candidate-provided information
- GitHub Pages deployment

## Safety and accuracy
JobSeek does not guarantee employment, visa approval, interviews, or a specific ATS score. It must not invent qualifications, employers, licences, experience, or achievements. Sponsorship information should be verified with the employer and relevant official authorities.

## Roadmap
1. Live job feed/database
2. Candidate authentication and profiles
3. Saved jobs and application tracking
4. Secure CV/document storage
5. Employer portal
6. Admin moderation and verification
7. Application analytics and interview preparation
8. Supabase-backed production data layer
